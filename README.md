# Typing Speed Test

A typing speed test application built with vanilla JavaScript that measures typing performance in real time.

## Demo
[Live Demo](https://typing-speed-testapp.netlify.app/)

## Features
- Random text generation
- Real-time WPM calculation
- Accuracy tracking
- Error detection
- Progress bar
- Multiple time modes (30s / 1min / 2min)
- Timer formatted as MM:SS
- Start-on-type functionality
- Result modal with final stats
- Reset functionality
- Responsive design

## Technical Notes
- Vanilla JavaScript (ES6)
- DOM manipulation
- Event-driven logic
- Finite state management with GAME_STATE
- setInterval timer handling
- Dynamic class updates for typing feedback
- CSS Grid + Flexbox layout
- Responsive UI with mobile breakpoints

## Responsive Design
- Mobile-friendly layout
- Adaptive stats grid
- Flexible textarea and typography
- Optimized modal sizing for smaller screens
